# Desktop builds

Manual build validation for Windows, Intel Mac and Apple Silicon Mac.

Only the owner can start a run for an exact reviewed source commit. The validation workflow is read-only. The separately gated candidate workflow can store checked builds as maintainer-only drafts here; it does not publish customer downloads or update information. Public logs show build-stage status; raw private build output is not uploaded.

This repository contains build instructions, not the application's development source. A passing build is not a published customer release.
